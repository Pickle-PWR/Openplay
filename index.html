Independent courts • win-button games • immediate next-player assignment • fair game distribution

Tournament Control

Open Play scheduling: There are no rounds and no fixed game duration. Each court runs independently. When a court finishes, tap the winning team button and it immediately receives the next available balanced matchup.
Pairing rule: The scheduler avoids repeat partners whenever a valid alternative exists, minimizes repeat opponents, and balances completed games across available players. If available courts are reduced during play, games already running on higher-numbered courts remain visible until finished.
